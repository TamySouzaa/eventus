## Requisitos Funcionais
RF-01: O sistema deve permitir inscrição em eventos e workshops.

RF-02: O sistema deve permitir cancelamento de inscrições conforme regras definidas.

RF-03: O sistema deve emitir certificados de participação.

RF-04: O sistema deve controlar automaticamente o número de vagas e gerenciar lista de espera.

RF-05: O sistema deve permitir consulta de participantes por palestrantes.

RF-06: O sistema deve permitir acompanhamento de inscrições em tempo real pelos organizadores.

RF-07: O sistema deve permitir validação de pagamentos pela equipe financeira.
