## Requisitos Não Funcionais
RNF-01: O sistema deve garantir segurança dos dados dos participantes.

RNF-02: O sistema deve estar disponível continuamente durante períodos de inscrição.

RNF-03: O sistema deve ser acessível em dispositivos móveis e desktop.

RNF-04: O sistema deve oferecer desempenho adequado para grande volume de inscrições simultâneas.

RNF-05: O sistema deve estar em conformidade com requisitos de privacidade e LGPD.
